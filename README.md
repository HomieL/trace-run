# trace.run

An interactive, game-like visualizer for common interview algorithms. Step through each solution line by line while Bit, a little robot guide, explains what every line does.

## Problems

- Backtracking: 78 Subsets, 90 Subsets II, 46 Permutations, 1239 Max Length of a Concatenated String
- Grids and graphs: 200 Number of Islands, 994 Rotting Oranges, 207 Course Schedule
- Trees: 102 Binary Tree Level Order Traversal
- Intervals: 56 Merge Intervals

## Run it

It's a single `index.html` with no build step. Open it in a browser, or serve it with GitHub Pages.

Link to a problem directly by adding its id to the URL, e.g. `#lc200`.

## Controls

- Next / Back: → and ← keys
- Play / pause: space
- Voice: reads each step aloud using the browser's text-to-speech
